# @ai-plugins-cc/gemini

Claude Code plugin that delegates to the Google Gemini CLI.

Maintained here until an official `gemini-plugin-cc` ships from Google. At cutover, this plugin will be replaced by a thin `gemini-adapter` (analogous to `codex-adapter`) and deprecated.
